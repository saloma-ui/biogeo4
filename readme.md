# Biologia i Geologia · 4t d'ESO

Repositori de materials de **Biologia i Geologia de 4t d'ESO**, publicats amb MkDocs.

## Estructura

- `docs/material/ud1/` … `docs/material/ud6/`: document principal i figures de cada unitat.
- `docs/activitats/ud1/` … `docs/activitats/ud6/`: activitats de cada unitat, organitzades per activitat i amb figures pròpies quan cal.
- `docs/index.md`: portada del lloc.
- `docs/programacio.md`, `docs/criteris-avaluacio.md` i `docs/calendari.md`: informació general del curs.

## Convencions de noms

Els noms de carpetes i fitxers es mantenen en minúscules, sense espais ni accents.

## Publicació

Els canvis a `main` activen GitHub Actions, que construeix el lloc amb MkDocs i el publica a `gh-pages`.

## Autoria i metodologia

Els materials segueixen un procés de disseny i revisió docent que pot incorporar assistència d'intel·ligència artificial generativa en la redacció, la creació de figures i la programació. La selecció i la responsabilitat editorial corresponen al docent.

Consulta la [declaració d'autoria i metodologia](docs/autoria-i-metodologia.md) o la [pàgina publicada al web](https://saloma-ui.github.io/biogeo4/autoria-i-metodologia/). Les figures sintètiques no s'han de confondre amb fotografies o microfotografies reals. Els recursos externs poden tenir condicions d'ús pròpies.
