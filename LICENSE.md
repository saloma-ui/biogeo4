# Llicències del repositori biogeo4

Aquest projecte té una **llicència doble** amb exclusions explícites:

1. **Continguts didàctics originals:** [CC BY-SA 4.0](LICENSE-CONTINGUTS.md). Text legal: https://creativecommons.org/licenses/by-sa/4.0/legalcode
2. **Codi informàtic original:** [MIT](LICENSE-MIT).
3. **Recursos de tercers, logotips, dades externes i elements de procedència encara no verificada:** no coberts automàticament per les llicències anteriors.

**Abast i exclusions:** [documentació del web](docs/llicencia.md).

**Fonts i comprovacions pendents:** [registre de recursos](docs/registre-recursos.md).

La concessió de llicència només abasta els drets que el titular pugui efectivament atorgar; no pressuposa drets exclusius sobre elements no protegibles, incloses certes imatges generades amb IA.
