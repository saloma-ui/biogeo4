# Biologia i Geologia — 4t d'ESO

Repositori del curs de **Biologia i Geologia de 4t d'ESO**.

El web del curs es genera amb **MkDocs Material** a partir dels continguts de la carpeta `docs/`.

## Estructura

- `docs/`: continguts publicables del web.
- `docs/programacio/`: informació general del curs.
- `docs/ud1/` … `docs/ud6/`: unitats didàctiques.
- `docs/udX/activitats/`: fitxes i activitats de cada unitat.
- `docs/udX/figures/`: imatges, mapes, esquemes i altres recursos gràfics.
- `docs/assets/`: recursos comuns del web.

> Aquest repositori és públic. No s'hi han d'incloure solucionaris, claus de correcció ni materials interns d'avaluació que no s'hagin de fer accessibles a l'alumnat.
