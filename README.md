# Biologia i Geologia · 4t d'ESO

Repositori de materials de **Biologia i Geologia de 4t d'ESO**, publicats amb MkDocs.

## Estructura

- `docs/ud1/` … `docs/ud6/`: presentació, temari i figures de cada unitat.
- `docs/activitats/ud1/` … `docs/activitats/ud6/`: activitats de cada unitat, amb les seves figures específiques.
- `docs/programacio/`: informació general del curs.
- `docs/assets/`: recursos comuns del lloc web.

## Publicació

Els canvis a `main` activen el flux de treball de GitHub Actions, que publica el lloc a la branca `gh-pages` mitjançant MkDocs.
