# Sobre aquest web

Aquest espai explica **com es preparen els materials de Biologia i Geologia de 4t d'ESO**, amb quines condicions es poden reutilitzar i com es documenta la procedència de les figures i altres recursos.

- [**Autoria i metodologia**](../autoria-i-metodologia.md) — Disseny pedagògic, procés de revisió i ús d'intel·ligència artificial.
- [**Llicència i reutilització**](../llicencia.md) — CC BY-SA 4.0 per als continguts propis i MIT per al codi propi, amb les exclusions corresponents.
- [**Crèdits i procedència**](../registre-recursos.md) — Autories de tercers, fonts i verificacions pendents.
- [**Inventari visual**](../inventari-visual.md) — Relació global de recursos gràfics i registres de procedència per unitat:
    - [UD01 · Geologia](../registre-figures-ud1.md)
    - [UD02 · La continuïtat cel·lular](../registre-figures-ud2.md)

Les imatges incorporades posteriorment queden registrades automàticament, inicialment com a **pendents de verificar**. L'automatització no determina per si sola si una imatge és real, sintètica o si els drets d'ús estan acreditats.
